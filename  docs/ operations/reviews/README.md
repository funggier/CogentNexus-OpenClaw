# Coordination Reviews

Reviews are written by ChatGPT after reading the matching Codex execution report and any referenced evidence.

## Recommended review format

```markdown
# CNX-YYYYMMDD-NNN — Review

Decision: ACCEPT | REWORK | BLOCKED | SUPERSEDED
Reviewer: ChatGPT

## Evidence reviewed

## Findings

## Decision rationale

## Remaining uncertainty

## Next task
```

A review is not a substitute for technical acceptance evidence. `ACCEPT` means the reported task satisfied its stated contract; broader release acceptance may still remain open.
