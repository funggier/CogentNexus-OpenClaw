# CogentNexus-OpenClaw v0.9.9

v0.9.9 consolidates the post-v0.9.8 runtime fixes, context-safety work, model-catalog refresh, and OpenClaw 2026.9.6 compatibility repair into one release line.

## Highlights

- physically qualified on OpenClaw `2026.9.6`;
- CogentNexus returns to MANAGED authority with OpenClaw-owned provider/model/auth routing;
- native Ollama terminal delivery is fenced from commentary/tool-progress rows;
- healthy long-running Ollama inference is protected from timer-only destructive recovery;
- soft context pressure stays non-blocking;
- hard context pressure can compact/trim before inference and resume durably;
- stale Direct execution can settle without accidental duplicate regeneration;
- supervisor recovery is fenced around active Direct leases;
- OpenAI/Ollama model catalog handling is refreshed;
- GPT-6 Astra, GPT-6 Sol, and GPT-6 Luna are physically qualified without fallback on the accepted 2026.9.6 route;
- OpenClaw 2026.9.6 Gateway restart convergence is supported with a bounded 180-second CNX restart-command budget.

## OpenClaw 2026.9.6 restart compatibility

Physical CNX-455 qualification measured one native OpenClaw 2026.9.6 Gateway restart at about `128.801` seconds. The previous CogentNexus inner subprocess budget was 60 seconds, so a correct cold-start could be treated as a failure even though the outer transactional activation budget was longer.

v0.9.9 preserves the existing fail-closed transaction and rollback boundaries but raises only the inner native restart-command budget to 180 seconds. The pre-repair activation rolled back safely; the repaired activation completed MANAGED qualification.

## Context safety

The post-v0.9.8 line adds two complementary context-pressure behaviors:

1. soft pressure remains advisory/non-blocking so normal conversation is not unnecessarily interrupted;
2. hard pressure can perform bounded semantic compaction or deterministic hard trimming before inference, then preserve durable continuation/resume authority.

Context safety does not weaken Ticket/session/generation ownership and does not silently switch providers.

## Ollama and Direct execution hardening

v0.9.9 carries forward and consolidates:

- native Ollama terminal-final fencing;
- protection for healthy long-running local inference;
- exact separation between elapsed deadlines and destructive interruption authority;
- stale Direct execution settlement without duplicate inference;
- supervisor recovery fencing around active Direct call leases.

The default physically qualified local route remains `ollama/qwen3.8:27b` with operational context `24576` and six-hour Ollama keep-alive on the accepted Windows host.

## Provider/model qualification

OpenClaw remains the provider/model/auth/routing authority for Cloud/pass-through routes.

Fresh MANAGED qualification on OpenClaw 2026.9.6 proved:

- `openai/gpt-6-astra`: requested/effective model matched, no fallback;
- `openai/gpt-6-sol`: requested/effective model matched, no fallback;
- `openai/gpt-6-luna`: requested/effective model matched, no fallback.

The package peer range is install compatibility only; physical operational acceptance is stated separately.
