# v0.9.5 Plan 1 Closeout Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close the remaining v0.9.5 Plan 1 architecture gaps without changing public version metadata, then prove provider neutrality through focused tests and fresh GitHub Actions evidence.

**Architecture:** Keep OpenClaw as the sole provider/model/auth/routing authority. CNX top-level lifecycle, including reset, controls only CNX-owned lifecycle/state; local adapter commands control only local adapter processes. Preserve legacy compatibility functions behind non-authoritative seams.

**Tech Stack:** Python 3, unittest/pytest, TypeScript/Vitest, SQLite, GitHub Actions, Windows PowerShell smoke tests.

**Spec:** `docs/superpowers/specs/2026-09-09-v0.9.5-architecture-repair-design.md`; `docs/superpowers/specs/2026-09-09-v0.9.5-local-provider-command-contract.md`; `docs/superpowers/plans/2026-09-09-v0.9.5-execution-index-and-shared-interfaces.md`.

## Global Constraints

- OpenClaw owns provider/model/auth/routing.
- CNX lifecycle commands must not select or commit a provider/model route.
- Local adapter lifecycle must not mutate OpenClaw routing.
- Provider/model changes must not increment CNX generation or force CNX lifecycle changes.
- Unknown/future providers must not require CNX registration.
- Preserve v0.9.4 exact Ticket/run/call, delivery, session-generation, terminal, quiescence, and recovery fences.
- No force push.
- No release/tag/public-version mutation during this closeout.
- Production changes follow RED -> minimal fix -> GREEN.
