# CogentNexus v0.6.2

Version 0.6.2 tunes durable local-model execution for large models and long artifacts while keeping retries bounded by failure class.

## Changes

- Automatically compiled Ollama steps now have a 180-minute overall timeout and a 60-minute inactivity timeout.
- Normal execution and validator failures remain bounded to three attempts.
- Timeout and transient transport failures may retry up to five attempts through `transientMaximumAttempts`.
- Workflow events record the selected failure class and effective retry ceiling.
- Ticket intake exposes `ticketMaximumAttempts`, including a tested five-attempt configuration.

## Verification

The Python workflow self-test covers the distinct normal and transient retry ceilings. The plugin tests verify generated manifest values and Ticket retry configuration. The complete validation suite is required before the release tag is published.
