# CogentNexus v0.6.1

Version 0.6.1 fixes Windows startup reconciliation after the Phase 6 release.

## Fixed

- Write the generated Task Scheduler definition as BOM-marked UTF-16 and declare the matching XML encoding.
- Validate the generated bytes on every platform so `startup.py ensure` cannot regress to an encoding mismatch.

The startup policy remains user-controlled and upgrades continue to preserve the persisted choice.
