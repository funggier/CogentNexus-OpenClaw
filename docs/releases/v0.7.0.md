# CogentNexus v0.7.0

CogentNexus v0.7.0 adds a durable Host Controller outside OpenClaw so accepted work can survive Gateway interruption, deliberate restarts, and machine reboot without making OpenClaw dependent on CogentNexus.

## Host-managed runtime

- `host.py` persists desired runtime state independently of OpenClaw.
- MANAGED mode owns Gateway/provider lifecycle and deterministic supervisor recovery.
- PASSTHROUGH mode disables the CogentNexus plugin, removes the managed `AGENTS.md` block, disables the CogentNexus supervisor, and returns lifecycle ownership to native OpenClaw.
- MAINTENANCE mode records deliberate shutdown so the supervisor does not fight operator intent.

## Ticket-first continuity

Windows managed installs now enable Ticket-first intake by default. Eligible owner messages are committed to SQLite before inference. A direct Ticket left accepted when Gateway is confirmed interrupted can be promoted to durable recovery after the runtime becomes healthy again.

The Host Controller can list and cancel Tickets and cancel all non-terminal Tickets for a session. Cancellation is terminal, fenced from later recovery, and produces a durable outbox record when the Ticket schema supports delivery.

## Installation

The Windows installer now:

1. installs and validates the skill and plugin;
2. installs the managed workspace policy;
3. creates `cnx.cmd` in the OpenClaw workspace;
4. initializes Host state;
5. enables Ticket-first plugin settings with one running Ticket workflow by default;
6. enables the hidden native Host supervisor; and
7. starts and verifies Gateway/Ollama unless `-SkipGatewayRestart` is supplied.

Useful commands from the workspace:

```powershell
.\cnx.cmd status
.\cnx.cmd start
.\cnx.cmd stop
.\cnx.cmd restart
.\cnx.cmd gateway restart
.\cnx.cmd ticket list
.\cnx.cmd ticket cancel <ticket-id>
.\cnx.cmd session cancel <session-key>
.\cnx.cmd disable
.\cnx.cmd enable
```

`disable` is intentionally different from `stop`: disabling enters PASSTHROUGH and leaves OpenClaw usable normally; stopping enters deliberate maintenance.

## Recovery invariant

Once a user message is durably accepted, CogentNexus must not silently lose it. It must eventually reach a terminal state: delivered/completed, cancelled, or explicitly failed with evidence.
