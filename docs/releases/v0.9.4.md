# CogentNexus-OpenClaw v0.9.4

CogentNexus-OpenClaw v0.9.4 is an **unreleased** stability and bug-fix candidate following v0.9.3. No v0.9.4 tag or GitHub Release exists yet; this file is pre-publication release-note source, not proof of release availability.

## Improvements

- Removes redundant periodic supervisor process boundaries on the healthy path.
- Gates durable delivery wakeups by Ticket, owner session, generation, and freshness authority.
- Prevents stale pending delivery rows from waking the heavy supervisor every minute.
- Preserves provider, stall-recovery, quiescence, lifecycle, and durable-delivery safety behavior.

## Compatibility

The managed local-provider contract remains Ollama on the validated OpenClaw `2026.7.1-2` baseline, including Ollama health, lifecycle, and recovery. Configured Cloud routes are OpenClaw-owned pass-through: OpenClaw owns authentication, routing/model selection, runtime, lifecycle, probing, and recovery; CogentNexus-OpenClaw owns continuity/Ticket/durable delivery only and never handles Cloud credentials. Existing v0.9.3 installations are intended to remain supported through the transactional installer; a v0.9.4 release archive may be used only after it is actually published and checksum-verified.

Quarantined plugin-rollover recovery is Windows-only and requires the explicit transaction file, its out-of-band expected SHA-256, and the expected replacement fingerprint. It fails closed before ordinary installation when any proof is absent or mismatched. There is no installer source-commit parameter.
