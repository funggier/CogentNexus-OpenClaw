# Task Loop

Use for multi-step or consequential work.

1. **Goal:** define the outcome and observable success criteria.
2. **Understand:** identify facts, unknowns, constraints, tools, dependencies, authorization, and risks.
3. **Plan:** choose the smallest actionable sequence; add checkpoints for longer work.
4. **Action:** execute the current step only; adapt when facts change.
5. **Check:** verify the actual result, errors, side effects, and whether the next step remains valid.
6. **Reflect:** classify the state:
   - **SUCCESS:** evidence meets the goal.
   - **CONTINUE:** the plan remains valid.
   - **REPLAN:** diagnose and choose a different route.
   - **BLOCKED:** only when external input or authority is genuinely required.

For complex work, track goal, success criteria, completed steps, current step, verified result, and next action. Do not narrate private reasoning or create approval rounds for safe in-scope actions.
