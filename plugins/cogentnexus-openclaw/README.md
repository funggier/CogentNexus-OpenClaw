# CogentNexus-OpenClaw Bridge — v0.9.6

This plugin is the OpenClaw-side bridge for durable Ticket admission, same-session serialization, Direct Recovery, delivery continuity, session/generation fencing, and compatibility ownership rules.

## Provider boundary

- Managed local-provider lifecycle: Ollama.
- Cloud/provider/model/auth routing: OpenClaw-owned pass-through.
- CogentNexus-OpenClaw never owns Cloud credentials or silently falls back to another provider.

## Ticket-first + pre-dispatch FIFO

Eligible owner messages are durably persisted before inference.

If an older Ticket in the same owner generation remains non-terminal, later accepted ingress waits at the claiming `before_dispatch` hook. It does not enter OpenClaw's native follow-up queue until the older Ticket settles.

For an authoritative user Stop:

1. owner generation advances once;
2. active + held Tickets are cancelled;
3. held cancelled ingress returns `handled:true` before Host queue admission;
4. no successor Host run is created for that held message.

CNX-442 physical acceptance on OpenClaw 2026.9.5 proved the held Ticket remained unbound with zero model calls and zero inference attempts.

## Restart recovery for held ingress

If Gateway restart destroys an in-memory `before_dispatch` waiter, accepted ingress with `bound_run_id IS NULL` may be reconstructed into Direct Recovery. Recovery remains FIFO-fenced behind older non-terminal ingress.

Bound active runs are not regenerated by this held-ingress mechanism.

## Direct Recovery invariants

- preserve Ticket owner session/generation;
- preserve provider/model provenance;
- do not regenerate after a durable result exists;
- fail closed on terminal/cancelled authority;
- tolerate bounded read-only SQLite BUSY/WAL contention;
- keep delivery retry separate from inference retry.

## Native restart compatibility

Historical compatibility modules retain OpenClaw 2026.7.1-2-specific shapes where required by regression tests. Current runtime acceptance additionally covers OpenClaw 2026.9.5. Do not rewrite version-specific compatibility code comments merely because the public package version advances.
