# CogentNexus v0.9.1

v0.9.1 is the first CogentNexus release checkpoint whose Windows Direct Recovery boundary is accepted for general single-node managed use on the validated OpenClaw `2026.7.1-2` baseline.

## Highlights

- Transactional MANAGED activation and PASSTHROUGH restoration.
- Ticket-first durable admission without forcing Direct conversation into generic workflows.
- External deterministic Host authority for managed lifecycle/recovery.
- Durable Direct Recovery with original provider/model provenance.
- Delivery Commit Gate separating model completion from confirmed user-visible delivery.
- Response-ready immutability and one durable direct result.
- v094 R2 authority-read hardening: read-only SQLite busy timeout plus transient BUSY tolerance so WAL contention cannot masquerade as durable authority revocation and create overlapping inference retries.
- v099 R5B4 native restart ownership fence for OpenClaw 2026.7.1-2: consume only the exact same-session/same-generation native restart continuation when CNX already owns Direct Recovery.
- Recursive recovery self-intake and same-session duplicate Ticket suppression.
- Startup/recovery residue hygiene and post-restart liveness fencing.
- Event/deadline-driven Host workers and lightweight healthy-path supervision with no periodic model inference.
- PASSTHROUGH and MAINTENANCE semantics preserved.

## Validation

The isolated release validation passed targeted v094 (3/3), targeted v099 (11/11), the full plugin suite (49 files / 237 tests), plugin validation/build, evaluation, and regenerated distribution hash fences matching the accepted live candidate.

## Operational classification

**Accepted core / operationally usable for general single-node managed use.**

Not claimed as fully production-hardened for:

- real power-loss/cold-boot recovery;
- OpenClaw versions newer than 2026.7.1-2;
- disk-full/database-corruption disaster recovery;
- very high concurrency/long soak;
- arbitrary external side effects without idempotency/receipt verification.

## Installation

Use the release archive plus `SHA256SUMS.txt`, then run `scripts/install.ps1`. For a backup-first purge and reinstall, use `scripts/clean-reinstall.ps1`.
