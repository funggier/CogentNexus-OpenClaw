# CogentNexus v0.6.0

Version 0.6.0 implements roadmap Phase 6 with a deterministic durability, retrieval, and scale evaluation gate.

## Added

- Isolated interruption benchmark proving expired-lease recovery, fencing advancement, and one terminal completion.
- Bounded retry benchmark proving retry ceilings and verified completion on the next attempt.
- Duplicate benchmark proving one Ticket and one modeled side effect for repeated intake.
- Fixed verified-lesson corpus measuring top-1 precision, recall at 3, provenance coverage, and p95 FTS5 latency.
- SQLite integrity, migration, ticket-count, and p95 write-latency evidence.
- Machine-readable report with canonical SHA-256 evidence digest and explicit semantic/PostgreSQL decisions.
- Phase 6 evaluation in main, tag, and release GitHub Actions gates.

## Measured architecture decision

The fixed Phase 6 corpus meets the FTS5 precision, recall, provenance, and latency gates, so v0.6.0 does not add embeddings. The isolated workload also remains within the SQLite ticket-volume and write-latency gates, so it does not add PostgreSQL. Both remain optional future adapters if later measured workloads cross the published thresholds.

This avoids turning an unproven intelligence or scale dependency into a durability dependency.
