# CogentNexus v0.8.2

v0.8.2 fixes managed local-provider recovery discovered during a real Windows v0.8.1 installation.

## Fixed

- `cnx enable` and `cnx start` now treat an explicit `--provider` lifecycle request as bounded authority to start the local Ollama provider even while autonomous low-level recovery remains fenced by `allowOllamaStart`.
- Host supervisor reconciliation now uses persisted `desiredProvider=running` to restore Ollama after a crash/reboot before continuing normal runtime supervision.
- Gateway-only lifecycle starts no longer fail merely because Ollama is intentionally unavailable.
- Windows managed Ollama startup prefers the deterministic `ollama serve` server command, with the desktop app retained as a fallback.

## Compatibility

No Ticket, policy, session-generation, or continuity schema changes from v0.8.1. Existing `.cogent` state and installed bridge data remain compatible.
