# CogentNexus v0.5.0

Version 0.5.0 implements roadmap Phase 5.1, Bounded External Research, on top of the v0.4.0 Ticket, workflow, Experience Store, and verified-lesson contracts.

## Added

- Persistent research-job state machine with legal terminal transitions.
- Explicit query, source, byte, elapsed-time, freshness, and corroboration budgets.
- Search/fetch capability-adapter interface with no implicit network authority.
- Canonical public-HTTPS source routing and official/primary/standard/research/maintainer source types.
- TTL source snapshots with publisher/origin, publication/access time, SHA-256 hash, bounded excerpt, and content type.
- External observations plus claim/evidence relationships for supports, contradicts, and mentions.
- Independent-origin corroboration so syndicated or mirrored content is not counted twice.
- Secret, credential, private/local URL, oversized-body, and prompt-injection gates.
- Optional `cogent_research` OpenClaw tool and `externalResearchEnabled` feature flag.

## Safety boundary

External content remains untrusted observation data. It cannot alter authorization, policy, validation, or tool scope, and it is never promoted automatically into a verified lesson. Turning the research feature off does not affect durable intake, recovery, validation, assembly, outbox delivery, or local knowledge retrieval.

## Validation

- TypeScript build and OpenClaw plugin validation.
- Plugin unit and integration suite, including fallback admission, state transitions, budgets, TTL reuse, provenance, corroboration, source laundering, secret redaction, private URL rejection, and injection isolation.
- CogentNexus Python validation and self-test suites.
- Cross-platform GitHub Actions release gate.
