# v0.9.5 Migration, Behavior Matrix, and Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Converge the provider/runtime, delivery/session, and Supervisor/idle repairs into one exact v0.9.5 candidate, prove upgrade compatibility and cross-subsystem behavior, then publish only after CI, Windows lifecycle, idle-quiescence, and live provider-switch acceptance pass.

**Architecture:** Migration preserves OpenClaw-owned route/auth/model and all durable CNX state. A central behavior matrix validates invariants across provider class, request lane, surface, runtime event, delivery evidence, and recovery state without an uncontrolled Cartesian explosion. Release uses one frozen candidate SHA through CI, install-over, live acceptance, merge, workflow dispatch, and post-publication artifact verification.

**Tech Stack:** Python, TypeScript/Vitest, GitHub Actions, PowerShell/Windows installer lifecycle, GitHub Release workflow, checksum/provenance scripts.

**Spec:** `docs/superpowers/specs/2026-09-09-v0.9.5-architecture-repair-design.md`; amendments `docs/superpowers/specs/2026-09-09-v0.9.5-local-provider-command-contract.md` and `docs/superpowers/specs/2026-09-09-v0.9.5-idle-quiescence-and-single-wake-contract.md`

## Global Constraints

- No release until all four v0.9.5 implementation plans are complete and full suites are green.
- Upgrade from v0.9.4 Cloud pass-through + plugin enabled must become active CNX without changing OpenClaw provider/model/auth route.
- Provider switch from Web Chat must not mutate CNX mode/generation, policy, plugin enable state, or Gateway lifecycle.
- Idle runtime must pass the no-heavy-wake acceptance gate.
- Disabled CNX must remain native OpenClaw.
- One exact candidate SHA must be used for CI, Windows acceptance, merge/release target, assets, checksums, and final report.
- No force push.
