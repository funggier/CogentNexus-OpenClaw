# CogentNexus v0.8.3

v0.8.3 fixes Windows managed shutdown semantics discovered during real end-to-end testing of v0.8.2.

## Fixed

- Windows Ollama shutdown now force-terminates the desktop/tray process tree and `ollama.exe` server tree so child processes cannot block or immediately respawn the provider.
- `cnx stop` now verifies the Gateway and, when requested, Ollama are actually down before reporting shutdown success.
- `safeToPowerOff` is now derived from verified component state rather than the Gateway stop command alone.
- A requested provider that remains healthy makes lifecycle stop return a non-zero status instead of falsely reporting a safe shutdown.

## Validation hardening

- The killed-controller workflow self-test now uses an explicit release-file handshake instead of fixed sleep timing, eliminating a Windows runner race while preserving the same fencing and recovery assertions.

## Compatibility

No Ticket, policy, delivery, or continuity schema changes from v0.8.2. Existing `.cogent` state remains compatible.
