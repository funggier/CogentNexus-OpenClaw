# CogentNexus v0.6.3

This release makes workspace-wide CogentNexus activation part of the default installation contract.

- Installers safely merge one managed CogentNexus block into `AGENTS.md`.
- Existing user-authored instructions are preserved and backed up before changes.
- Repeated installation updates the same block without duplicates.
- Incomplete managed markers fail closed instead of rewriting an ambiguous file.
- `--skip-agents-policy` / `-SkipAgentsPolicy` remains available when another policy layer provides equivalent admission.
- CogentNexus Core is now explicitly documented as part of the [CogentNexus Ecosystem](https://github.com/funggier/cogentnexus-ecosystem).
