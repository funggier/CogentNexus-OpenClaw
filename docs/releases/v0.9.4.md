# CogentNexus-OpenClaw v0.9.4

CogentNexus-OpenClaw v0.9.4 is a stability and bug-fix release following v0.9.3.

## Improvements

- Removes redundant periodic supervisor process boundaries on the healthy path.
- Gates durable delivery wakeups by Ticket, owner session, generation, and freshness authority.
- Prevents stale pending delivery rows from waking the heavy supervisor every minute.
- Preserves provider, stall-recovery, quiescence, lifecycle, and durable-delivery safety behavior.

## Compatibility

The managed local-provider contract remains Ollama on the validated OpenClaw `2026.7.1-2` baseline; configured Cloud routes are supported through OpenClaw-owned pass-through. Existing v0.9.3 installations remain supported through the transactional installer and may be upgraded using the v0.9.4 release archive.

## Verification

This release is intended to be published only after exact-SHA repository/package CI, supported Windows installation, and bounded live scheduled-task requalification pass for the same candidate SHA. GitHub Releases/tags remain authoritative for publication and artifact identity.
