# CogentNexus-OpenClaw v0.9.5

> Pre-publication release notes. This file is intentionally not a publication announcement until every v0.9.5 release gate passes.

## Release intent

v0.9.5 consolidates the provider/runtime, delivery/session identity, and Supervisor idle-quiescence repairs into a provider-independent OpenClaw bridge contract.

## Verified implementation changes

- CNX execution remains independent of the currently selected OpenClaw provider/model.
- OpenClaw retains ownership of provider, model, authentication route, and provider lifecycle.
- CNX durable execution preserves Ticket/session identity across provider changes and gateway restarts.
- Canonical delivery/session identity rules fail closed for ambiguous Discord receipt identity and stale session generation.
- Supervisor idle handling uses single-wake authority and rejects heavy work when there is no actionable durable work.
- v0.9.4 migration contracts cover managed, maintenance, disabled/passthrough, and cloud-passthrough states without inventing provider authority.
- Current operator naming remains namespace-isolated under `CogentNexus-OpenClaw` / `cnxclaw`.

## Release gates still required

The following must pass on one frozen candidate SHA before publication:

1. Exact repository-wide v0.9.5 metadata consistency, including `package-lock.json`.
2. Full Python and plugin validation suites on supported CI platforms.
3. Windows v0.9.4 -> v0.9.5 install-over acceptance.
4. Live provider-switch acceptance with OpenClaw Web Chat.
5. Idle-quiescence acceptance with zero heavy wake, provider recovery, configuration mutation, or gateway lifecycle action.
6. Exact candidate provenance, archive checksums, merge, and post-publication artifact verification.

No claim of live provider-switch, Windows install-over, or publication readiness is made by this document until those gates are evidenced.
