# Capability Registry

Use before selecting tools or recovery actions.

    cogent capability sync
    cogent capability list
    cogent capability find "GitHub repository"
    cogent capability inspect github.cli
    cogent capability check github.cli

The registry at .cogentnexus-openclaw/capabilities.json indexes runtime features, selected executables, and discovered OpenClaw skills. It is a shallow machine-readable index, not a replacement for detailed skill/tool contracts. Refresh availability before consequential work.
