## Trigger

The supported installer from exact candidate:

`076d76d5465798753eda5146cdaa9cf7da72b5ff`

successfully crossed:

- plugin rollover prepare;
- local-package plugin install with capability consent;
- post-install plugin disable;
- rollover finalize;

The installer then failed during post-install Host enable.

The emitted Host-enable failure showed:

- MANAGED authority committed;
- OpenClaw Gateway process running and owning `127.0.0.1:18789`;
- Ollama healthy;

  - `attempts=2`;
  - `timeoutSeconds=30`;
  - `initialDelaySeconds=3.0`;
- transaction rolled back to PASSTHROUGH generation `108`.

Native rollback subsequently reached Gateway health after:

- `5` readiness attempts;
- approximately `81.469s`.

Earlier CNX-431 live qualification had already measured the same OpenClaw 9.5 startup class at approximately `78.593s`.

## Root cause

`skills/cogentnexus-openclaw/scripts/runtime.py::lifecycle_cmd(start)` still hardcoded:

`wait_for_runtime_health(..., timeout_seconds=30, ...)`

and emitted:

`verification.timeoutSeconds = 30`

This is a third independent readiness boundary that retained the pre-OpenClaw-9.5 startup assumption after CNX-431 and CNX-432 repaired the Host-native and shared runtime-boundary paths.

Because one Gateway status probe can itself consume most of the 30-second budget, the lifecycle start path observed only two attempts before failing closed.

## Required semantics

1. `lifecycle start` remains bounded.
2. OpenClaw 9.5 cold/readiness transients are tolerated within a maximum 180-second startup budget.
3. Existing strict Gateway health truth remains unchanged.
4. Provider readiness is required only when the caller explicitly requests `--provider`.
5. Maintenance is cleared only after verified healthy runtime.
6. Budget exhaustion still fails closed with exit code `2`.
7. Shutdown verification timing remains unchanged.
8. No provider routing, Ticket, delivery, supervisor hard-hang, or ownership semantics change.
9. Verification evidence must report the actual configured lifecycle-start readiness budget.
